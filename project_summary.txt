============================================================================================================================================================================================
PROJECT SUMMARY: MakeMyTrip - Autonomous Web Operations Agent
============================================================================================================================================================================================
Ek GenAI-powered autonomous agent je MakeMyTrip website par Flights, Trains, Buses, Cabs, Hotels, Villas, Attractions, Holiday Packages, ane Cruises search kare chhe - free Gemini API thi, koi paid API(Claude/OpenAI) vagar.

Aa file ma aakha project ni sharu-thi-ant sudhi ni safar step-by-step varnavi chhe.

============================================================================================================================================================================================
STEP 1: PROJECT CONCEPT & ARCHITECTURE SAMJAVU
============================================================================================================================================================================================
Shu thayu:
- Project no concept nakki karyo: LLM-driven web agent je hardcoded selectors vagar, natural language instructions thi website operate kare.
- Architecture samjavi: User Task -> LLM Brain (Gemini) -> Action decide -> Playwright execute -> Loop repeat -> Structured JSON output.
- Tech stack nakki karyo: browser-use (agent framework), Playwright (browser automation), Google Gemini (free LLM), Streamlit (UI).

Tyar bad shu thayu: Environment setup taraf aagad vadhya.

============================================================================================================================================================================================
STEP 2: ENVIRONMENT SETUP
============================================================================================================================================================================================
Shu thayu:
- "mmt-agent" naam nu project folder banavyu.
- Python virtual environment (venv) banavyu ane activate karyu.
- Playwright install karta vakhte "uvx not recognized" ane "No module named playwright" jeva errors aavya - fix karyu: venv activate karvanu bhulai gayu hatu, pip thi playwright install karyu, pachi chromium browser download karyu.

Tyar bad shu thayu: Free Gemini API key levi ane basic agent test karvo.

============================================================================================================================================================================================
STEP 3: FREE API KEY + BASIC AGENT TEST
============================================================================================================================================================================================
Shu thayu:

- "test_agent.py" banavi - ek basic test jema agent MakeMyTrip par jaine homepage na tabs identify kare.
- Pehlo successful run: browser khulyu, MakeMyTrip par gayu, tabs batavya, pachi browser band thayu (normal behavior).

Tyar bad shu thayu: Real flight search automate karva "flight_search.py" banavyu.

============================================================================================================================================================================================
STEP 4: FLIGHT SEARCH AUTOMATION + DEBUGGING
============================================================================================================================================================================================
Shu thayu (ghana errors aavya ane fix karya):
1. "5 consecutive failures" error - popup/modal agent ne block kari rahyu hatu - task prompt ma popup-handling instructions add kari.
2. "'BaseApiClient' object has no attribute '_async_httpx_client'" error - library version mismatch hatu - packages update karya (browser-use, google-genai).
3. "'str' object has no attribute 'model_copy'" - test code ni bhool hati, correct UserMessage format vaparyu.
4. "503 UNAVAILABLE - model overloaded" - Gemini server temporarily busy hatu - model "gemini-flash-lite-latest" par switch karyu.
5. FINALLY SUCCESS: Agent e login popup close karyu, From/To city select kari, calendar handle karyu, search kari, ane real flight results (IndiGo, Air India - actual prices) extract karya.

Tyar bad shu thayu: Output ne structured JSON banavva taraf vadhya.

- Result: Clean JSON output + automatically "flight_results.json" file ma save thayu.
